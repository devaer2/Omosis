# Omosis Android V12

This Android project packages the complete Omosis V12 marketplace into a native Android WebView shell.

## Included
- Existing Omosis V12 storefront and seller/admin pages
- Existing Supabase integration files
- Native Android share bridge
- Local storage/cart support through WebView
- GitHub Actions APK build workflow

## Build on GitHub
Upload the contents of this folder to the repository root. Open **Actions → Build Omosis APK → Run workflow**.
When the run finishes, open it and download the **Omosis-V12-APK** artifact.

The generated installable file is `app-debug.apk`.
